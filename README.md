# HAX API Key Settings

A standalone Lit and HAX DDD component prototype for [HAX issue #2837](https://github.com/haxtheweb/issues/issues/2837).

## Local development

```sh
npm install
npm start
```

Open the URL printed by the development server.

## First prototype

Use sample data to render YouTube as a built-in provider with an Enabled toggle
and a field for replacing its key. Drive the form from a provider definition.
